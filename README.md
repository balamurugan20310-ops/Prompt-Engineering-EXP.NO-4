## 2. Identify Prompt Patterns and Answers
### A. Comparative Analysis Prompt
1. “Compare and contrast deep learning and machine learning.”

| Feature            | Machine Learning            | Deep Learning                     |
| ------------------ | --------------------------- | --------------------------------- |
| Definition         | AI that learns from data    | Advanced ML using neural networks |
| Data Need          | Works with smaller datasets | Requires large datasets           |
| Feature Extraction | Manual                      | Automatic                         |
| Complexity         | Less complex                | More complex                      |
| Speed              | Faster training             | Slower training                   |
| Accuracy           | Good                        | Very high for complex tasks       |

#### Conclusion:
  Deep learning is a powerful extension of machine learning used for complex tasks like image and speech recognition.

2. “How do renewable and non-renewable energy sources differ?”

| Feature      | Renewable Energy           | Non-Renewable Energy           |
| ------------ | -------------------------- | ------------------------------ |
| Source       | Naturally replenished      | Limited resources              |
| Examples     | Solar, wind, hydro         | Coal, oil, gas                 |
| Pollution    | Low                        | High                           |
| Availability | Unlimited                  | Limited                        |
| Cost         | High setup, low usage cost | Lower setup, high running cost |

#### Conclusion:
  Renewable energy is sustainable and eco-friendly, while non-renewable energy is limited and polluting.

### B. Experiential Perspective Prompt

1. “As a software engineer, what are the benefits of using cloud computing in your projects?”

As a software engineer, cloud computing helps me store and manage data easily without needing physical servers. It allows me to access resources from anywhere and collaborate with team members efficiently. Cloud platforms improve scalability, reduce costs, and provide secure backup and recovery options. It also helps in faster deployment of applications.

2. “From a student’s perspective, describe the challenges of online learning.”

From a student’s perspective, online learning can be challenging due to poor internet connection and lack of face-to-face interaction with teachers. It can be difficult to stay focused at home because of distractions. Some subjects require practical learning, which is harder online. Long screen time can also cause tiredness and stress.

### C. Everyday Functioning Prompts

1. “Describe the role of machine learning in everyday apps like YouTube or Netflix.”

Machine learning is used in YouTube and Netflix to analyze user behavior such as watch history, likes, and searches. It then recommends personalized videos and movies based on user interests. It also helps in content ranking, advertisement targeting, and improving user experience.

2. “How is encryption used in daily life when sending WhatsApp messages?”

Encryption in WhatsApp converts messages into a secure code before sending them. Only the sender and receiver can read the messages using a secret key. This protects chats, photos, videos, and calls from hackers or unauthorized users. It ensures privacy and secure communication in daily life.
